Overview

What the simulator was built to do

The project was designed to model and visualize how a CubeSat responds to attitude control commands over time. Instead of treating the problem as only equations on paper, the simulator turns the dynamics into something interactive and easier to study.

By combining state propagation, control logic, visualization, and repeated trial runs, the tool becomes useful both for learning spacecraft dynamics and for comparing how different controller settings affect stability and pointing performance.

Capabilities

Main features

  • Simulated spacecraft attitude motion using quaternion-based kinematics to avoid the singularities associated with Euler angles.
  • Applied PD control to drive the spacecraft toward a desired orientation and evaluate response behavior over time.
  • Included animation and interface elements so users can adjust conditions and immediately see how the vehicle responds.
  • Used Monte Carlo analysis to study how initial condition variations influence control performance and pointing error trends.
Technical Approach

How the model comes together

Dynamics and control

The core model propagates rotational motion while the controller continuously computes corrective torques based on attitude error and angular rate. That creates a full closed-loop simulation rather than a static calculation.

Interactive evaluation

Wrapping the analysis in a GUI makes it much easier to test assumptions, compare cases, and communicate the effect of controller tuning choices without digging through multiple separate scripts.
