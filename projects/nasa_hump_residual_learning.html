Overview

Problem statement and project scope

The engineering question behind this project is straightforward and important: can a low-cost RANS solution be corrected toward LES-like mean-flow behavior in a separated-flow region without pretending that the result is a universal turbulence model? This project answers that question with a disciplined case-specific workflow built around the NASA wall-mounted hump benchmark.

The hump case is a strong test because it includes acceleration over the hump, an adverse pressure gradient downstream, and a separated reverse-flow region that standard eddy-viscosity closures often struggle to predict accurately. The report is careful about scope: the final model is a benchmark- specific mean-flow correction framework, not a replacement for LES or a transferable closure law.

Reference data

NASA LES mean-flow data supply the correction target, while independent NASA PIV profiles are held back for a separate validation step.

Baseline physics

A steady incompressible SST-RANS solution in OpenFOAM provides the low-fidelity field that the residual model corrects rather than replaces.

Learning target

The model predicts streamwise-velocity residuals, which preserves the baseline CFD field as a physically meaningful starting point.

CFD Baseline

From NASA structured grid to OpenFOAM SST-RANS

The main CFD setup began from NASA-supplied structured PLOT3D hump grids. The selected grid, hump2newtop_noplenumZ409x109, was converted into OpenFOAM using plot3dToFoam and reconstructed into six physical boundaries: inlet, outlet, front and back symmetry planes, a slip top wall, and a no-slip lower hump wall.

  • The final mesh contained 44,064 hexahedral cells with acceptable quality for preliminary RANS analysis and the expected high-aspect-ratio near-wall structure needed for boundary-layer resolution.
  • The solver setup used steady incompressible SST-RANS, which was chosen because the hump case is fundamentally a separated-flow turbulence-model challenge rather than a compressibility problem.
  • A uniform inlet was first used for setup verification, then replaced with an approximate turbulent one-seventh-power-law inlet profile to better reflect the incoming experimental boundary layer.
  • The flow field was initialized with potentialFoam, advanced for 800 pseudo-iterations, exported to VTK, and then post-processed for interpolation, feature assembly, and figure generation.

The key physical deficiency in the baseline was not subtle: the SST-RANS solution captured acceleration over the hump and general low-momentum behavior downstream, but it failed to reproduce the strong near-wall reverse-flow region seen in the LES and experimental data.

That mismatch shows up clearly in both the field contours and the extracted velocity profiles. The baseline solution preserves the overall flow topology, but it stays too positive near the wall in the separated region and does not recover the reverse-flow pocket seen in the higher-fidelity reference.

Residual Learning

Learning the correction instead of the whole flow field

Rather than asking a model to infer the entire flow from geometry alone, the project learns a residual on top of the RANS baseline. That is a much better formulation for this problem because the baseline CFD already captures a large amount of the correct structure; the machine-learning model only needs to learn the systematic error associated with separated-flow underprediction.

Inputs

The full model uses eight local features combining baseline RANS mean-flow information, turbulence-model state information, and spatial coordinates. That feature design makes the model aware of both local physics and where the sample lives within the fixed benchmark geometry.

Network setup

The report describes a multilayer perceptron trained on normalized inputs and normalized residual targets, using SiLU activations, mean-squared-error loss, AdamW optimization, and early stopping based on validation loss behavior.

Three model variants were compared during blocked validation: coordinates-only, RANS-only, and the full combined model. That ablation structure matters because it separates geometric interpolation from genuinely useful local CFD information.

Once the residual is added back to the baseline field, the corrected solution recovers the LES-like separated-flow structure much more faithfully than the original RANS field. The difference is visible both in the reconstructed contour map and in the station profiles through the recovery region.

Validation Design

Why the blocked-region test is the strongest part of the workflow

A random point split would have made this problem artificially easy because training and test samples would sit beside each other inside the same smooth field. Instead, the project withholds a continuous downstream separated-flow region from LES training and evaluates the model only inside that hidden block.

  • Baseline hidden-region RMSE versus LES was 0.4253 for SST-RANS.
  • A coordinates-only model reduced hidden-region RMSE to 0.0908, a 78.7% improvement.
  • A RANS-only model reduced hidden-region RMSE to 0.1078, a 74.7% improvement.
  • The full residual model reduced hidden-region RMSE to 0.0140, corresponding to a 96.7% improvement over baseline RANS.

The project then goes one step further and compares the corrected field against independent NASA PIV measurements at hidden stations x/C = 1.03, 1.10, and 1.17. That is a meaningful second validation layer because PIV was not used in AI training.

Results

What improved and why it is credible

The corrected field recovers the LES-like low-momentum and reverse-flow behavior that baseline SST-RANS misses in the separated region. At the hidden PIV stations, profile RMSE drops from 0.4451 for baseline RANS to 0.1484 for the AI-corrected field, which is a 66.7% improvement relative to the independent experimental data.

Field behavior

The AI correction reconstructs the downstream low-speed pocket and near-wall reverse-flow structure instead of simply smoothing the baseline solution.

Profile behavior

At hidden stations, the corrected profiles move from the overly positive RANS result toward the LES and PIV curves, especially near the wall where separation matters most.

Training behavior

The loss history drops by several orders of magnitude while keeping validation loss above but near training loss, which supports the blocked-region generalization claim.

The report's most important judgment call is also its most credible one: it explicitly says this is not a universal closure model. The work is presented as a benchmark-specific RANS-to-LES mean-flow correction framework, which is exactly the right level of claim for the evidence shown.
