AI + Propulsion Project

Machine Learning–Assisted Turbofan Engine Performance Optimizer

Project Overview

This project is a MATLAB-based turbofan engine performance optimizer that combines thermodynamic engine cycle analysis with machine learning surrogate modeling. The tool allows users to run baseline turbofan cycle calculations, train AI models, optimize design variables, and compare key engine performance outputs.

Key Features

  • Generated 8,000 simulated turbofan engine-cycle samples for machine learning model training.
  • Built an interactive MATLAB GUI for baseline cycle calculations, AI training, and optimization.
  • Predicted thrust, fuel consumption, thermal efficiency, propulsive efficiency, and overall efficiency trends.
  • Implemented sensitivity analysis to identify which inputs most strongly influence engine performance.
  • Created a design-space exploration workflow to compare baseline and optimized cycle behavior.

Technical Approach

The project uses thermodynamic turbofan cycle relationships to generate training data across a range of engine design variables. A machine learning surrogate model is then trained to approximate engine performance outputs and support faster design-space exploration.

The optimizer uses the trained surrogate model to search for improved combinations of design variables. Sensitivity analysis is used to evaluate which inputs have the greatest effect on the outputs.
