Overview

What this project does

This tool lets you run turbofan engine cycle analysis the fast way — rather than computing every performance point from scratch, a machine learning surrogate model trained on 8,000 simulated samples approximates performance outputs nearly instantly, enabling rapid design-space sweeps that would otherwise take significant computation time.

Users interact through a single MATLAB GUI: adjust design variables (bypass ratio, pressure ratio, turbine inlet temperature, etc.), run a baseline cycle, train the AI model, and evaluate optimized conditions — all from one interface with live performance comparisons.

Features

Key capabilities

  • Generated 8,000 simulated turbofan engine-cycle samples across a sweep of design variable combinations to build a comprehensive training dataset.
  • Built an interactive MATLAB GUI unifying baseline cycle calculations, AI model training, optimization, and performance visualization in a single tool.
  • Predicted thrust, thrust-specific fuel consumption (TSFC), thermal efficiency, propulsive efficiency, and overall efficiency from surrogate model outputs.
  • Implemented sensitivity analysis to quantify which input variables (bypass ratio, fan pressure ratio, TIT, etc.) most strongly drive each performance metric.
  • Created a design-space comparison workflow to benchmark optimized cycle conditions against a user-defined baseline side by side.
Technical Approach

How it works

The workflow has two phases: physics-based data generation, then machine learning acceleration. Thermodynamic cycle relationships produce a ground-truth dataset; the surrogate model learns to replicate those outputs without re-running the full cycle each time.

Phase 1 — Cycle Data Generation

Turbofan thermodynamic cycle equations (fan, compressor, combustor, turbine, nozzle stages) sweep across a Latin hypercube-style grid of design variables to produce 8,000 labeled performance samples covering the realistic design space.

Phase 2 — Surrogate Modeling & Optimization

A machine learning surrogate is trained on the generated dataset. Once trained, the surrogate replaces expensive cycle recalculations during optimization sweeps, enabling rapid gradient-free search over the design space and sensitivity ranking of input variables.

Results

Takeaways

This project brought together propulsion theory, machine learning, and software engineering in one tool. Building the full pipeline — from generating physics-based training data, to training a predictive model, to wrapping it in a usable GUI — gave me hands-on experience with how AI accelerates traditional engineering analysis.

The sensitivity analysis output was particularly useful: seeing quantitatively which design variables drive efficiency vs. thrust helps frame propulsion trade studies in a way that raw cycle calculations alone don't surface easily.
