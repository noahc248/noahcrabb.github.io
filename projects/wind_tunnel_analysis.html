Overview

Purpose of the experiment

This project examined how velocity changes across a turbulent boundary layer by collecting pressure data in the wind tunnel and converting it into usable flow information. The goal was to connect hands-on measurements with the theory covered in aerodynamics coursework.

It was a strong applied exercise in experimental methods: setting up instrumentation, checking data quality, processing measurements carefully, and translating raw readings into physical trends that could be compared against expected boundary layer behavior.

Workflow

From measurements to analysis

  • Collected velocity profile data with a 30-port pneumatic rake across several operating conditions in the wind tunnel.
  • Converted pressure readings into velocity information and organized the datasets for consistent comparison.
  • Used MATLAB to plot profiles, normalize results, and identify trends in the turbulent boundary layer.
  • Compared measured behavior to theoretical expectations to interpret profile shape, thickness growth, and flow development.
Technical Focus

Key engineering takeaways

Experimental technique

The value of this project came from learning how sensitive aerodynamic measurements are to setup, calibration, and data handling. Even straightforward profile measurements depend on careful procedure to produce meaningful trends.

Data interpretation

Post-processing turned a large set of readings into something useful: profile plots, condition-to-condition comparisons, and a clearer understanding of how real flow data lines up with simplified theory.
